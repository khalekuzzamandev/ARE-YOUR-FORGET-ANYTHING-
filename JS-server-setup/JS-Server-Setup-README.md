## 📌 Setup Overview

1. Create the JavaScript server.
2. Install the required packages.
3. Configure the server.
4. Create the MongoDB connection.
5. Store the MongoDB URI inside `.env`.
6. Connect the backend with MongoDB.
7. Start the server.
